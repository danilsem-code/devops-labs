# DevOps Labs 🚀

Мой путь в DevOps-инженера. Здесь я собираю лабораторные работы, скрипты и проекты.

## 📚 Что внутри

- **scripts/** — Bash и Python скрипты для автоматизации
- **configs/** — Конфигурационные файлы
- **logs/** — Логи и отчёты
- **.github/workflows/** — CI/CD pipeline

## 🛠️ Стек технологий

- **OS:** macOS, Linux (WSL)
- **Языки:** Bash, Python
- **Инструменты:** Git, GitHub, GitHub Actions
- **В планах:** Docker, Kubernetes, Ansible, Prometheus, Grafana

## 🎯 Мои проекты

### 1. Система мониторинга серверов
- **check_system.sh** — проверяет доступность серверов, место на диске, ошибки в логах
- **ping_monitor.py** — многопоточная проверка серверов через ping
- **log_parser.py** — парсер логов с поиском ошибок

### 2. CI/CD Pipeline
- Автоматическая проверка Python и Bash при каждом пуше
- Настроен через **GitHub Actions**
